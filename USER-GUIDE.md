# Morelord Craftworks User Guide

For Craftworks 0.4.6 on Foundry VTT v14 and dnd5e 5.3+.

The maintained guides are:

- [Game Master Manual](docs/gm-manual.md): setup, Content Packs, Harvest, Gather, Loot, Hoard, Delerium Search, generators, custom recipes, and troubleshooting.
- [Player Manual](docs/player-manual.md): materials, recipes, crafting, shared inventories, and acquisition sessions.
- [Documentation overview](docs/README.md): module overview and illustrated workflows.

The dashboard's **Documentation** button opens the current in-game guide. **Acquire** contains GM resource and treasure tools; **Craft** contains catalogs and projects; **Tools** contains potion, scroll, and spellbook generators.

Potion and scroll results support adding entries through the full filtered catalog picker and removing individual entries before sharing or awarding. Availability counts follow category and school selections. Delerium Search awards original Monsters of Drakkenheim compendium items to the chosen character or party Recipient.
