# Morelord Craftworks 0.1.0

Initial public release of Morelord Craftworks.

## Highlights

- GM-initiated harvesting, gathering, encounter loot, and treasure hoard workflows.
- Searchable Materials and Recipes reference browsers.
- Content Pack architecture for Standard and premium content.
- Actor-inventory material tracking and Party/Group recipient support.
- Recipe planning, crafting progress, and marked-recipe Craft workflow foundations.
- Morelord Core entitlement integration boundary and Morelord Marketplace material integration helpers.
- Foundry VTT v14 and D&D5e 5.3+ support baseline.

## Installation

Install using the permanent manifest URL documented in README.md. Future updates can then be installed through Foundry's normal module update flow.
